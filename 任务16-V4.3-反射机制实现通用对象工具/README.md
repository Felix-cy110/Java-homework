## 迭代目标

基于前面 MVC、注解、AOP 日志体系，利用Java 反射 API开发通用对象工具类，解决重复写对象拷贝、对象转字符串、字段判空的样板代码问题。 实现通用工具，不绑定特定实体类（User、CampusResource、ReserveRecord 均可复用）；不新增业务功能，属于底层工具层重构，减少重复代码，为任务 15 日志切面的参数序列化提供底层支撑。

说明：纯 JDK 原生反射，不引入任何第三方工具包（如 Jackson、BeanUtils）。原有业务、日志、统计功能保持不变。

## 验收标准（原文）

- ObjectReflectUtil静态工具类存在，构造方法私有；
- objectToString：传入任意实体对象，反射读取字段生成字符串，空对象正常处理；
- copyProperties：同名同类型字段自动拷贝，类型不匹配自动跳过不报错；
- isAllFieldNull：正确判断对象全部字段是否为空；
- LogAspect 日志切面使用该工具完成入参 / 结果序列化，日志内容正常生成；
- 原有全部业务、日志、统计报表功能正常运行，无功能退化。
