## 环境与编译运行

本次实际验证环境：Windows x64，Oracle JDK `1.8.0_341`，目录 `D:\jdk8`；`java -version` 为 `1.8.0_341`，`javac -version` 为 `1.8.0_341`。系统默认 `java` / `javac` 是 `17.0.12`，因此以下命令显式使用 JDK 8。若移到其他电脑，替换 JDK 和项目路径。

在 PowerShell 执行：

```powershell
Set-Location 'D:\MyProject\Java-homework\任务01-V1.0-项目初始化'
New-Item -ItemType Directory -Force -Path out | Out-Null
& 'D:\jdk8\bin\javac.exe' -encoding UTF-8 -Xlint:all -classpath out -d out src\SystemMain.java
if ($LASTEXITCODE -ne 0) { throw '编译失败，请先检查上方错误。' }
chcp 65001 | Out-Null
& 'D:\jdk8\bin\java.exe' '-Dfile.encoding=UTF-8' -cp out SystemMain
```

源文件采用 UTF-8；运行命令将当前终端代码页与 Java 编码统一为 UTF-8，以显示中文。`-classpath out` 将编译和运行依赖限定在本项目输出目录。只打开本任务目录即可编译，不需要其他任务、Maven、Gradle或第三方库。也可在 IDE 中将本任务单独作为 Java 项目打开，设置 JDK 8、源码编码 UTF-8、`src/` 为源码目录，并运行 `SystemMain.main`；IDE 导入未在本次自测中执行。
