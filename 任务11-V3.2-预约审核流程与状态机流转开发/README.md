## 迭代目标

基于任务 9 基础预约功能，补全完整预约状态机，规范全部预约状态流转逻辑；实现管理员完整审核流程、驳回原因记录、状态联动资源变更、非法状态拦截；彻底杜绝状态乱跳、流程错乱、资源状态不联动等问题。

本任务核心价值：让学生真正学会 状态机设计 + 流程闭环控制，是软件构造重要业务建模能力。

## 验收标准（原文）

- 四种预约状态正常展示，枚举生效，无字符串乱输入
- 只能按合法流程流转，非法状态变更全部拦截、友好提示
- 驳回操作可填写驳回原因，记录持久化保存
- 审核时间自动记录
- 审核通过 → 资源自动占用
- 通过后取消预约 → 资源自动释放
- 资源被占用时，学生无法继续预约
- 学生只能取消自己的可取消状态预约
- 所有查询使用 Stream，无空指针异常
- 全部业务返回统一 Result、异常提示友好、无堆栈报错
